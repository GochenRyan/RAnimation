# 基础规范：坐标系与矩阵约定

核对日期：2026-11-23。

## 规范速查

| 项目 | 约定 |
| --- | --- |
| 世界坐标系 | **右手系，+Y 向上** |
| 世界长度单位 | **米** |
| 角色零旋转时 | **前方 −Z、右方 +X、上方 +Y** |
| 相机视空间 | **朝 −Z 看**，使用右手视图矩阵 |
| 向量与乘法 | **列向量**，`p' = M × p`；Shader 使用 `mul(M, p)` |
| 实例变换 | `M = T × R × S`，先缩放、再旋转、最后平移 |
| 父子变换 | `子节点世界矩阵 = 父节点世界矩阵 × 子节点局部矩阵` |
| 矩阵存储 | **GLM 列主序**；当前 Shader 上传路径与其匹配 |
| 深度 | NDC 深度范围 **[0, 1]**，已启用 **reversed-Z：近 1、远 0** |
| 深度测试 | 清屏深度 **0**，比较 **GREATER_EQUAL** |
| 三角形正面 | **CCW，背面剔除**；资产预期为 `rightHanded` 绕序 |
